# Luck & Fortune — First visual prototype

A responsive, static frontend preview with English, Sorani Kurdish, and Arabic language switching.

## Open locally
Open `index.html` in a browser.

## Publish with GitHub Pages
Upload the contents of this folder to the root of your `luck-and-fortune` repository. Then open Settings → Pages and deploy from the `main` branch, root folder.

## Important
This is a visual prototype only. It does not include user registration, email verification, database, referrals, ticket accounting, payments, or a live prize draw. Do not accept payments or run a paid chance-based draw until legal and payment-provider requirements have been checked.
